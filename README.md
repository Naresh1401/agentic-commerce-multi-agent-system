# Multi-Agent Commerce System

Standalone repository split from `agentic-commerce-platform`.

## What This Demonstrates

Supervisor-routed multi-agent workflow for meal planning, product discovery, pricing, inventory, cart, coupon, and checkout.

This is a demo/training project. It uses mock grocery data only. It does not use real Kroger APIs, real payment APIs, real customer data, or secrets.

## Setup

```bash
make setup
```

## Run

```bash
make run
```

## Verify

```bash
make test
```
